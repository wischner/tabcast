# disciple/lib/

Project libraries and third-party libraries, one directory each, as
`lib/<name>/`.

Nothing here yet. Sources placed under `lib/<name>/` are found and
built automatically by the project `Makefile`, so adding a library
means adding the directory and nothing else.

Third-party code is linked statically. See section 7 of
`docs/standards/CPP-CODING-STYLE.md`.
